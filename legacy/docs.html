Mako Desk

$MAKO is a memecoin with its own on-chain trading desk. It runs natively on Elysium, reads Hyperliquid's order books through a precompile, makes markets on HyperCore, and burns its profits.

Most memecoins depend entirely on attention. $MAKO adds a working mechanism underneath. A treasury contract, MakoDesk, quotes two-sided markets on HyperCore under hard risk limits. Realized profit is used to buy $MAKO on the open market and send it to the burn address. Everything happens in contracts and can be checked on the explorer.

Quickstart

You need an EVM wallet (Rabby, MetaMask, OKX Wallet) and some HYPE.

  1. Open the app at makodesk.xyz/app and click Connect wallet.
  2. Add Elysium. The app will prompt you to add the network, or you can add it manually using the values below.
  3. Bridge HYPE from HyperEVM to Elysium (see Bridging). HYPE is the gas token, so keep a small amount for fees.
  4. Swap HYPE for $MAKO on the Swap tab, then use Add token so your wallet shows your balance.

Bridging HYPE

Elysium uses native HYPE for gas, bridged 1:1 from HyperEVM, so there's no separate gas token to buy.

  • Native bridge: deposits arrive in minutes. Withdrawals back to HyperEVM currently take about 24 hours.
  • Instant routes: Relay, Enso and Jumper offer fast bridging in both directions for a fee.
Elysium is a young chain: one sequencer, a whitelisted validator set, and permissionless fraud proofs (BoLD) still on the roadmap. Size your positions with that in mind.

The Desk

MakoDesk is the treasury contract that trades. It runs a simple, auditable market-making loop on HyperCore:

  1. Sense. It reads the HYPE-PERP order book (full depth), mid price, funding and recent liquidations through Elysium's market-data precompile. Data is at HyperCore block granularity (~70 ms) and about 150–350 ms fresh inside the EVM.
  2. Decide. It computes a fair price, applies inventory skew and a spread set by the current mood, and checks every risk limit.
  3. Quote. It places and cancels resting orders on HyperCore through ElysiumCoreWriter in about 100 ms, using a trade-only agent on the desk's own HyperCore sub-account.
  4. Settle. Realized PnL is tallied each epoch. Profit goes to buyback & burn.

Who triggers the loop?

Anyone. poke() is permissionless and pays a small HYPE tip to the caller, so quoting doesn't depend on a team-run server. A public keeper is provided as a fallback.

Custody model

  • The HyperCore agent can place and cancel orders only. It has no transfer or withdraw permission.
  • Desk capital lives in the contract and its dedicated HyperCore sub-account, never in a team wallet.
  • Parameter changes go through a 48-hour timelock and are announced on @makodesk before they take effect.

Risk controls

Market making can lose money, so the limits are enforced by the contract itself.

ControlLaunch valueBehaviour
Max position2,500 HYPE notionalOrders that would exceed it are rejected on-chain.
Max daily loss$4,000When hit, the desk cancels all quotes and pauses until the next UTC day.
Max drawdown15% of desk capitalTriggers the kill-switch. Resuming needs a timelocked call.
Inventory skew±40%Quotes lean toward reducing inventory past this band.
Stale data guard> 750 msIf precompile data is stale, the desk cancels and waits.
Kill-switchpublicAnyone can trigger it when any limit is provably breached.

Caps start small and are raised only once the desk has a public track record, always through the timelock.

Mood Engine

Mako's mood is a public on-chain state derived from HyperCore funding and liquidation flow. It does two jobs: it changes how the desk quotes, and it gives the community a live signal to rally around.

Wick detector

If HYPE drops more than a threshold within a few HyperCore blocks while liquidations spike, the desk enters Breach and arms a wick bonus. The next settlement burns at 2× the normal share, still funded only from realized profit.

Buyback & burn

  • At each epoch, 80% of realized desk profit buys $MAKO from the official pool and sends it to 0x000…dEaD. The other 20% is kept as desk capital.
  • Burns are never funded from principal. A losing epoch burns nothing.
  • Each burn emits Burned(amount, reason, epoch) and appears in the app's Burn log with its transaction.

Integration

Other contracts can read the desk's state, for example to build on the mood signal or show burn stats.

IMakoDesk.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

interface IMakoDesk {
    enum Mood { Feeding, Hunting, Cruising, Circling, Breach }

    struct DeskState {
        Mood    mood;
        int256  fundingE8;       // 1h funding, 1e8 = 1%
        uint256 midPriceE8;      // HYPE-PERP mid, USD 1e8
        int256  positionE8;      // signed HYPE notional
        int256  realizedPnlUsdE6;
        uint256 totalBurned;     // MAKO, 18 decimals
        bool    paused;
        uint64  coreBlock;       // HyperCore block of last read
    }

    function mood() external view returns (Mood);
    function state() external view returns (DeskState memory);
    function poke() external;    // permissionless; tips caller in HYPE

    event Quoted(uint64 indexed coreBlock, uint256 bidE8, uint256 askE8, uint256 sizeE8);
    event Filled(uint64 indexed coreBlock, bool isBuy, uint256 pxE8, uint256 szE8, int256 edgeUsdE6);
    event MoodChanged(Mood from, Mood to, int256 fundingE8);
    event Burned(uint256 amount, bytes32 reason, uint256 indexed epoch);
    event KillSwitch(address indexed caller, bytes32 reason);
}

Reading from a frontend

read-mood.js
// viem example
import { createPublicClient, http } from "viem";

const client = createPublicClient({ transport: http(ELYSIUM_RPC) });
const MOODS = ["Feeding", "Hunting", "Cruising", "Circling", "Breach"];

const mood = await client.readContract({
  address: MAKO_DESK,
  abi: [{ name: "mood", type: "function", stateMutability: "view", inputs: [], outputs: [{ type: "uint8" }] }],
  functionName: "mood",
});
console.log("Mako is", MOODS[mood]);
About the precompile ABI. Kinetiq hasn't published the final interfaces for the market-data precompile and ElysiumCoreWriter yet. MakoDesk wraps them behind an internal adapter, so the public interface above stays the same when they ship. Until then, community tools such as Precompilisium serve HyperEVM-style HyperCore reads.

App configuration

The website, app and docs all read from one file, assets/js/config.js. To go live:

  1. Fill in chain with the official Elysium chain ID, RPC and explorer.
  2. After deployment, set contracts.token, contracts.lp and later contracts.desk.
  3. Set links.swap, links.bridge and links.chart.
  4. When the desk is live, set previewMode: false. This removes the preview banners and switches the dashboard to on-chain reads.

Security

  • Token: minimal OpenZeppelin ERC-20 with no owner functions, verified source.
  • Desk: external audit before the desk holds capital. The report will be linked here.
  • Agent keys: trade-only. A leaked key can't move funds, and losses are bounded by the on-chain caps.
  • Chain risk: Elysium is new and currently runs one sequencer with whitelisted validators. Outages or reorgs can affect the desk. The stale-data guard cancels quotes when reads lag.
  • Bug bounty: report issues to security@makodesk.xyz.

FAQ

Is the desk live?

Not yet. It needs Elysium's Phase 2 upgrade. The app's preview mode shows how it will behave, and every simulated number is labelled as such.

Can the desk lose money?

Yes. Losses are capped per day and in total, and quoting pauses automatically when a limit is hit. Burns only come from realized profit.

Why no tax?

Taxes hurt liquidity and look like a cash grab. The desk is meant to earn from the market, not from holders.

Where is the official contract address?

Only on makodesk.xyz, these docs and @makodesk.
